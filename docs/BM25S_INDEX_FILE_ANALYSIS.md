## 4. Vocab Buckets 结构

每个 Vocab Entry 的格式：

```cpp
struct VocabEntry {
    uint64_t token_hash;      // 8 bytes - token 的 hash 值
    int32_t  token_len;       // 4 bytes - token 字符串长度
    char     token_data[];    // 变长    - token 字符串
    uint32_t token_id;        // 4 bytes - token ID
    int64_t  posting_offset;  // 8 bytes - posting 在文件中的偏移
    int32_t  posting_count;   // 4 bytes - posting 数量
    int32_t  reserved;        // 4 bytes - 保留
};
// 固定部分: 32 bytes + token_len bytes
```
